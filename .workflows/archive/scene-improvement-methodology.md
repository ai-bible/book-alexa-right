# Методология анализа и улучшения сцен

**Версия**: 1.0
**Создано**: 2025-11-27
**Применимость**: Все сцены sci-fi романа

---

## ОБЗОР

Шестифазная методология для систематического анализа и улучшения литературного текста сцен. Использует hat-thinks (sequentialthinking) для многогранной проработки, затем ручное применение правок.

---

## ФАЗА 1: Техническая проверка (Thriller Architect)

### Чеклист обязательных элементов

| Критерий | Вопрос для проверки | Красный флаг |
|----------|---------------------|--------------|
| **Конфликт в каждом бите** | Есть ли столкновение желаний/препятствий в КАЖДОМ абзаце? | Абзацы чистого описания без напряжения |
| **In Media Res** | Начинается ли сцена УЖЕ в кризисе (без подводки)? | "Она пришла домой и села..." |
| **Активный протагонист** | Персонаж ДЕЙСТВУЕТ или только наблюдает/реагирует? | Пассивное наблюдение событий |
| **Мир через трение** | Технологии/мир показаны через ПРОБЛЕМЫ, не через экспозицию? | Абзацы объяснения как работает мир |
| **Эмоции через тело** | Физические симптомы вместо названных эмоций? | "Она почувствовала страх/грусть/радость" |
| **Плотность** | Каждый абзац продвигает 2+ элемента (сюжет/персонаж/мир)? | Абзацы с одной функцией |

### Примеры

**Конфликт:**
- ❌ "Она сидела в капсуле и смотрела в окно."
- ✅ "Она сидела в капсуле, прижимая запястье к груди — холод фантомного прикосновения не уходил, сколько ни три."

**In Media Res:**
- ❌ "После того как Алекса вернулась из салона, она поднялась на лифте и вошла в капсулу."
- ✅ "Спина прижата к стене. Запястье в ладони. Холод — там, где пальцев нет."

## ФАЗА 2: Проверка прозы

### Паттерны для поиска и исправления

#### 2.1 Избыточная фрагментация
- **Проблема**: Слишком много коротких предложений подряд утомляет читателя
- **Правило**: Фрагментация только для УДАРНЫХ моментов
- **Исправление**: Объединять описательные фрагменты, сохранять короткие для кульминаций

```
❌ Плохо (всё фрагментировано):
"Кухня. Небольшая. Стол. Окно. Женщина."

✅ Хорошо (фрагментация для удара):
"Кухня обняла её теплом — маленькая, пропитанная светом.
Женщина у плиты что-то напевала.
Лицо мелькнуло.
Не её лицо.
Лина."
```

#### 2.2 Telling вместо Showing
- **Проблема**: Автор ОПИСЫВАЕТ вместо того чтобы ПОКАЗЫВАТЬ
- **Правило**: Читатель должен сам сделать вывод из показанного

```
❌ Telling: "Голос не имел интонации."
✅ Showing: "Слова упали в воздух. Как камни. Ровные. Мёртвые."

❌ Telling: "Он испугался её реакции."
✅ Showing: "Он отступил на шаг. Медленно. Так отступают от собаки, которая вдруг оскалилась."
```

#### 2.3 Фильтр-слова
- **Проблема**: Посредник между читателем и ощущением
- **Правило**: Убирать "она увидела/услышала/почувствовала" — давать сенсорику напрямую

```
❌ С фильтром: "Она услышала шёпот, похожий на шелест листьев."
✅ Без фильтра: "Шелест сухих листьев пронёсся по слуховым нервам."

❌ С фильтром: "Она увидела, что таймер горит красным."
✅ Без фильтра: "Таймер на веках полыхнул алым — цифры жгли сетчатку."
```

#### 2.4 Клише
- **Проблема**: Стёртые метафоры не создают образ
- **Правило**: Искать свежие биологические/технические/профессиональные метафоры

```
❌ Клише: "Сердце сжалось от страха."
✅ Свежее: "Что-то в грудной клетке дёрнулось — не сердце, глубже."

❌ Клише: "Время остановилось."
✅ Свежее: "Время растягивалось, когда ты один на один со страхом."
```

#### 2.5 Ритм
- **Правило**: Длина предложений соответствует эмоциональному состоянию
- Длинные, вьющиеся → паранойя, дезориентация, погружение
- Короткие, рубленые → паника, действие, удар
- Вариация между ними → живой текст

## ФАЗА 3: Глубина и внутренний конфликт

### 3.1 Внутренняя борьба

**Вопрос**: Персонаж СОПРОТИВЛЯЕТСЯ происходящему или пассивно принимает?

**Техника — структура "объяснение → НО опровержение":**
```
*Это был сбой оборудования*, — она заставляла себя думать.
Но Лина знала её имя.
*Наведённая галлюцинация. Паразитный сигнал.*
Но Лина **держала** её за руку.
```

### 3.2 Профессиональное знание как инструмент

**Вопрос**: Используется ли экспертиза персонажа как щит И уязвимость?

- **Щит**: Алекса применяет профессиональные техники (мнемонические маркеры)
- **Уязвимость**: Техники не работают на себе ("как хирург, оперирующий собственный мозг")
- **Глубина**: Профессиональное знание делает аномалии СТРАШНЕЕ ("купленные воспоминания не транслируют температуру с такой точностью")

### 3.3 Эмоциональные слои

**Вопрос**: Что персонаж ГОВОРИТ себе vs. что ПРОИСХОДИТ на самом деле?

```
Поверхность: "Профессиональная возможность. Золотая Терраса. 5 лет оплаты."
Правда: "Она бы приняла вызов, даже если бы платили ноль."
```

### 3.4 Тело выдаёт правду

**Вопрос**: Есть ли неосознанные физические реакции, которые персонаж не контролирует?

```
✅ "Коридор превращался в размытое пятно — не от скорости, а от слёз, которые она не замечала."
✅ "Руки не дрожали — это было странно. После всего они должны были дрожать."
```

## ФАЗА 4: Стилистическое качество

### Критерии высокого качества (из анализа консультанта)

| Элемент | Слабый вариант | Сильный вариант |
|---------|----------------|-----------------|
| **Абстрактные концепции** | "память клиента" | "золотистые струны эйфории, серые узлы скуки, пульсирующие красным сгустки травмы" |
| **Физические ощущения** | "таймер горел красным" | "цифры жгли сетчатку, как раскалённое клеймо" |
| **Откровения/глитчи** | "Лицо мелькнуло. Лины." | "мелькнуло *нечто*. Тень. Лишний кадр в киноплёнке." |
| **Звук** | "она услышала шёпот" | "шелест сухих листьев пронёсся прямо по слуховым нервам" |
| **Функция персонажа** | Диалог без контекста | "Дэвид был якорем. Напоминанием о том, что где-то есть нормальная жизнь." |
| **Страх/эмоция другого** | "В его глазах был страх" | "Так отступают от собаки, которая вдруг оскалилась. Опаска." |
| **Мысли через действие** | Персонаж говорит что думает | Поза/жест показывает (отступает не поворачиваясь спиной, закрывает дверь слишком мягко) |

### Ключевые принципы

1. **Многослойность метафор** — каждая метафора работает на нескольких уровнях
2. **Физическое проникновение** — звуки/ощущения не просто воспринимаются, а проходят СКВОЗЬ тело
3. **Нарастание перед откровением** — не давать сразу, строить саспенс
4. **Контраст** — показывать изменение (обычно тёплые глаза → сейчас страх)

## ФАЗА 5: Формат вывода анализа

### Структура отчёта

```markdown
## АНАЛИЗ СЦЕНЫ [ID]

### СЛАБЫЕ МЕСТА (приоритизированы)

**P1 — Логика/Канон:**
#1: [описание проблемы]
- БЫЛО: "..."
- СТАЛО: "..."
- ПОЧЕМУ: [объяснение]

**P2 — Telling → Showing:**
#2: [описание]
- БЫЛО: "..."
- СТАЛО: "..."

**P3 — Внутренний конфликт:**
#3: [описание]
- ДОБАВИТЬ: "..."
- ГДЕ: [после строки X]

**P4 — Стилистический polish:**
#4: [описание]
- БЫЛО: "..."
- СТАЛО: "..."

### СИЛЬНЫЕ МЕСТА (НЕ ТРОГАТЬ)

#1: [строки X-Y]
- ТЕКСТ: "..."
- ПОЧЕМУ РАБОТАЕТ: [объяснение]

#2: [строки X-Y]
- ТЕКСТ: "..."
- ПОЧЕМУ РАБОТАЕТ: [объяснение]

### ИТОГ

| Приоритет | Количество | Оценка сложности |
|-----------|------------|------------------|
| P1 | N | Высокая/Средняя/Низкая |
| P2 | N | ... |
| P3 | N | ... |
| P4 | N | ... |

**Рекомендация**: Применить P1-P2 обязательно, P3-P4 по желанию.
```

## ФАЗА 6: Приоритизация правок

### Уровни приоритета

| Приоритет | Тип | Критерий | Действие |
|-----------|-----|----------|----------|
| **P1** | Логические ошибки | Противоречия канону, нелогичные действия, сломанная причинность | ОБЯЗАТЕЛЬНО исправить |
| **P2** | Telling → Showing | Прямые замены описаний на показ | ОБЯЗАТЕЛЬНО исправить |
| **P3** | Внутренний конфликт | Добавление борьбы персонажа, эмоциональных слоёв | РЕКОМЕНДУЕТСЯ |
| **P4** | Стилистический polish | Метафоры, ритм, поэтика, свежие образы | ПО ЖЕЛАНИЮ |

### Правило применения

1. **Сначала P1** — без этого текст сломан
2. **Затем P2** — базовое качество прозы
3. **P3 если есть время** — глубина и резонанс
4. **P4 для финального polish** — превращает хороший текст в отличный
